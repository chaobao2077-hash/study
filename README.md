# 单词储蓄罐

一个用于积累和练习英语单词的小工具。

## 在线使用

当前版本：[打开单词储蓄罐](https://word-piggy-bank-20260914.chaobao2077.chatgpt.site)

## 功能

- 输入英文后，从本地英汉词典快速填写中文释义
- 用简单例句和搭配生成四选一填空题
- 答对后提高掌握度
- 答错后展示图片和例句辅助记忆
- 学习进度保存在当前浏览器中

## GitHub Pages

仓库已经按静态网站结构保存。进入仓库 **Settings → Pages**，选择 **Deploy from a branch**，分支选择 **main / (root)** 并保存，即可生成公开网址。

词典数据来源于 [ECDICT](https://github.com/skywind3000/ECDICT)。
